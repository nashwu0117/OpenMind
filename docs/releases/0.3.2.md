# OpenMind 0.3.2 Preview — macOS Apple Silicon

繁體中文 · English below

## 下載與安裝

- **M 系列 Mac（Apple Silicon／arm64），macOS 13 或更新版本。** 本次沒有 Intel 或通用版本。
- [下載 DMG 安裝檔](https://github.com/nashwu0117/OpenMind/releases/download/preview-0.3.2/OpenMind-darwin-arm64-0.3.2.dmg)，打開後將 **OpenMind** 拖到 **Applications／應用程式**，再從應用程式資料夾開啟。
- 也可下載 ZIP，解壓縮後把 `OpenMind.app` 拖到應用程式資料夾。DMG 和 ZIP 內是同一版 app，擇一下載即可。
- 這是 **ad-hoc 簽署、尚未經 Apple 公證的預覽版**。首次開啟若被阻擋，先嘗試開啟 App，再到 **系統設定 → 隱私權與安全性 → 仍要打開** 個別允許 OpenMind，並確認提示。請確認下載來源是本專案的 GitHub Release；不需要整體停用 Gatekeeper。
- `SHA256SUMS.txt` 提供 DMG 與 ZIP 的 SHA-256 校驗值。在下載資料夾執行 `shasum -a 256 -c SHA256SUMS.txt` 可核對檔案；只下載其中一種格式時，另一筆會顯示檔案不存在。

## 功能與限制

繁體中文／英文介面、九種圖表結構、本機文件、大綱、列印預覽、內嵌繁中字型 PDF、Markdown／OPML／FreeMind 子集與 SVG／PNG 輸出。

升級前請另存 `.openmind` 文件備份。本次預覽版以手動下載方式更新；應用程式內更新服務會忽略預覽版，下載與重啟更新流程尚未完成真實版本往返驗收。沒有 Intel 或乾淨 Mac 的安裝驗收，也不宣稱無需系統確認即可開啟。其他範圍見 [README](https://github.com/nashwu0117/OpenMind#readme) 和 [已知限制](https://github.com/nashwu0117/OpenMind/blob/main/docs/KNOWN_LIMITATIONS.md)。

本次在 macOS 27.0.1 arm64 通過 104 項單元測試、4 項更新測試、40 項 Chromium 操作測試，以及開發版、封裝版和從 DMG 安裝副本的原生儲存／開啟／列印驗收。DMG 和 ZIP 完整性、巢狀簽章與安裝副本已檢查。更新介面測試使用模擬伺服器回應，不代表真實自動更新已驗收。

## Download and install

- **Apple Silicon (M-series / arm64) Macs, macOS 13 or later.** No Intel or universal build is included.
- [Download the DMG installer](https://github.com/nashwu0117/OpenMind/releases/download/preview-0.3.2/OpenMind-darwin-arm64-0.3.2.dmg), open it, drag **OpenMind** to **Applications**, and launch it from Applications.
- Alternatively, download the ZIP, extract it, and drag `OpenMind.app` to Applications. Both formats contain the same app; choose either one.
- This is an **ad-hoc-signed preview without Apple notarization**. If macOS blocks first launch, try opening the app, then allow OpenMind under **System Settings → Privacy & Security → Open Anyway** and confirm the prompt. Verify the download came from this project's GitHub Release. You do not need to disable Gatekeeper globally.
- `SHA256SUMS.txt` contains the DMG and ZIP checksums. Run `shasum -a 256 -c SHA256SUMS.txt` in the download directory. If you downloaded only one format, the other entry will report a missing file.

## Features and limits

Traditional Chinese and English interfaces, nine diagram structures, local documents, outline, print preview, PDFs with embedded Traditional Chinese fonts, Markdown / OPML / a documented FreeMind subset, and SVG / PNG export.

Back up `.openmind` files before upgrading. Update this preview by downloading manually; the in-app update service ignores prereleases and an actual download/install/restart update round trip remains unverified. Intel and clean-Mac installation are not verified, and first launch may require system approval. See the [README](https://github.com/nashwu0117/OpenMind#readme) and [known limitations](https://github.com/nashwu0117/OpenMind/blob/main/docs/KNOWN_LIMITATIONS.md).

On macOS 27.0.1 arm64, 104 unit tests, 4 updater tests, 40 Chromium E2E tests, and native save/open/print checks passed for development, packaged, and DMG-installed copies. DMG/ZIP integrity, nested signatures, and the installed copy were checked. Update UI checks use a simulated server response and do not validate real automatic updates.

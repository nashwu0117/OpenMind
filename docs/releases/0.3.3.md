# OpenMind 0.3.3 Preview — macOS Apple Silicon

繁體中文 · English below

## 這次更新

- **資料夾分類：** 啟動後先進入心智圖資料庫，可新增、重新命名與移除資料夾。移除資料夾會保留內部心智圖並移至「未分類」。
- **卡片右鍵選單：** 按右鍵或點選 ⋯，即可開啟、重新命名、建立副本與移動心智圖，也支援鍵盤選單操作。
- **獨立編輯頁：** 點選心智圖後進入自己的編輯頁，可一鍵返回資料庫。重新整理與瀏覽器前後頁會保留對應文件。
- **保留全部文件：** 移除最近八份文件的儲存上限，資料夾分類在重新啟動後仍會保留。
- **更新提示修正：** 預覽版清楚說明手動下載更新，並提供下載頁面的按鈕，不再嘗試讀取沒有正式版本的更新來源。

## 下載與安裝

- 適用於 **Apple Silicon／M 系列 Mac（arm64），macOS 13 或更新版本**。不提供 Intel 或通用版本。
- [下載 0.3.3 DMG](https://github.com/nashwu0117/OpenMind/releases/download/preview-0.3.3/OpenMind-darwin-arm64-0.3.3.dmg)。打開後將 **OpenMind** 拖到 **Applications／應用程式**；若已有舊版，先關閉 OpenMind，再取代原本的 App，完成後重新開啟。
- 也可下載 ZIP，解壓縮後將 `OpenMind.app` 放到應用程式資料夾。DMG 與 ZIP 內含相同的 App，擇一即可。
- 升級前可另存 `.openmind` 文件備份。安裝檔不包含使用者文件；更新不需要刪除 OpenMind 的本機資料。
- **0.3.2 的更新按鈕仍可能顯示「網路失敗」**，請直接使用本頁下載連結；安裝 0.3.3 後，更新視窗會說明正確的手動更新方式。

這是 **ad-hoc 簽署、尚未經 Apple 公證的預覽版**。首次開啟若被阻擋，確認下載來源是本專案 GitHub Release 後，可在 **系統設定 → 隱私權與安全性 → 仍要打開** 個別允許 OpenMind。不需要整體停用 Gatekeeper。

`SHA256SUMS.txt` 提供 DMG 與 ZIP 的校驗值；在下載目錄執行 `shasum -a 256 -c SHA256SUMS.txt` 即可核對。只下載其中一種格式時，另一筆會顯示檔案不存在。

## 本次驗證

114 項單元測試、9 項更新測試、49 項 Chromium 操作測試、正式建置與依賴檢查均通過（0 個已知依賴漏洞）。封裝版與從唯讀 DMG 複製出的 App 通過資料夾／右鍵分類、獨立編輯頁、雙語手動更新入口、單一執行個體、原生儲存／開啟與 PDF 輸出驗收。App 與 8 個內嵌元件的簽章、ZIP／DMG 完整性、Applications 捷徑及 SHA-256 均已檢查。

## 限制

本次採手動下載與安裝，沒有自動替換及重新啟動更新。Developer ID 簽署、公證、Intel、乾淨 Mac 安裝及真實自動更新往返仍未驗收。其他範圍見 [已知限制](https://github.com/nashwu0117/OpenMind/blob/main/docs/KNOWN_LIMITATIONS.md)。

## What's new

- **Folders:** Open the map library first and organize maps in folders. Removing a folder keeps its maps in Unfiled.
- **Card menus:** Right-click or select ⋯ to open, rename, duplicate or move a map. Keyboard menu navigation is supported.
- **Dedicated editing pages:** Each map opens on its own page with a return action and working history/reload navigation.
- **Keep all maps:** Remove the eight-document storage limit and retain folder assignments across restarts.
- **Clear update guidance:** Preview builds explain manual updates and offer a download-page button instead of querying an unavailable stable update feed.

## Download and install

- For **Apple Silicon (M-series / arm64) Macs, macOS 13 or later**. No Intel or universal build is included.
- [Download the 0.3.3 DMG](https://github.com/nashwu0117/OpenMind/releases/download/preview-0.3.3/OpenMind-darwin-arm64-0.3.3.dmg). Quit OpenMind, open the DMG, drag **OpenMind** to **Applications**, replace the old app if present, then reopen it.
- Alternatively, extract the ZIP and move `OpenMind.app` into Applications. Both formats contain the same app.
- Save a separate `.openmind` backup before upgrading. The installer contains no user documents, and updating does not require deleting local OpenMind data.
- Version **0.3.2 may still show a misleading network error**. Download from this page instead; version 0.3.3 explains manual updates in its update dialog.

This is an **ad-hoc-signed preview without Apple notarization**. If macOS blocks first launch, confirm the download came from this GitHub Release, then allow OpenMind under **System Settings → Privacy & Security → Open Anyway**. You do not need to disable Gatekeeper globally.

Verify downloads with `shasum -a 256 -c SHA256SUMS.txt`. If you downloaded only one format, the other entry will report a missing file.

## Verification

114 unit tests, 9 updater tests, 49 Chromium E2E tests, the production build and dependency checks passed (0 known dependency vulnerabilities). Both the packaged app and a copy installed from the read-only DMG passed folder/context-menu navigation, dedicated editing, bilingual manual-update links, single-instance, native save/open and PDF checks. App and 8 nested signatures, ZIP/DMG integrity, the Applications link and SHA-256 checksums were verified.

## Limits

This preview uses manual installation. Developer ID signing, notarization, Intel, clean-Mac installation and an actual automatic update round trip remain unverified. See [known limitations](https://github.com/nashwu0117/OpenMind/blob/main/docs/KNOWN_LIMITATIONS.md).

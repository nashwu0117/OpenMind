# Roadmap

1. Initial complete slice: local editor + shared vector layout + native save/recovery + print planner and PDF. Acceptance evidence goes in VERIFICATION.md.
2. Improve print fidelity with bundled redistributable CJK fonts, annotation-heavy fixtures, connector continuations in reflow mode, page-aware branch splitting, printer calibration and raster visual baselines.
3. Dedicated brace/fishbone/matrix/tree-table layouts and mixed per-branch structures, anchored summaries and richer line styling.
4. Real-world .xmind/FreeMind import corpus with loss reports, attachments and DOCX/XLSX/PPTX/TextBundle conversion. Publish compatibility only per tested format/version.
5. Presentation, date-aware task dependencies and business-calendar Gantt, version history and personal template library.
6. Optional local/BYOK AI with granular payload consent; opt-in self-hosted CRDT collaboration with identity/permissions/conflict tests; Web Clip and device integrations.

Desktop signing/notarization, Windows/Linux CI and accessibility audit precede a production release. This repository starts at 0.1; it is not presented as a finished XMind replacement.

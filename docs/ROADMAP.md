# Roadmap — after 0.3.0

已交付：本機編輯與原生保存、v1保源升v2、九種版面、摘要／附件／公式、個人主題範本、任務依賴與日曆日甘特圖、簡報及PDF、FreeMind子集、繁中嵌字型與六策略列印、兩種可展開專注預覽。證據與真實範圍見 [COMPLETION_AUDIT](COMPLETION_AUDIT.md)。

1. 公開穩定版准出：正式簽署公證、乾淨機安裝升級、實體列印、Windows/Linux、完整輔助科技與多視窗衝突保護。
2. 深化本機專業能力：分支混合結構、方向與群組、矩陣可編輯欄、工作日／假日排程、永久版本封存、效能拆載入。
3. 格式：以合法corpus實驗.xmind／Office／TextBundle，逐格式版本記錄欄位損失，不能由文字子集推定完全相容。
4. 選配服務：明確同意與可替換provider的本機/BYOK AI；有身分權限與衝突測試的自架CRDT協作，再評估Web Clip／裝置整合。
